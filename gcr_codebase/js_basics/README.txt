ASSIGNMENT 1 — JavaScript Q1 to Q8

Each question is in a separate JavaScript file: Q1.js through Q8.js.

How to run using Node.js:
1. Extract this ZIP file.
2. Open the extracted folder in VS Code or a terminal.
3. Run a question with: node Q1.js
4. Replace Q1.js with Q2.js, Q3.js, etc.

You can also paste each file's code into your browser's developer console.

Note: Q8's supplied requirements end after the five-year projection and the incomplete line
“Not eligible yet.”, so this file implements the five-year salary projection only.
